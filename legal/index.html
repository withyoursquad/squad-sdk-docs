    Intellectual Property

    Squad Line Patent

    Squad Line's interactive voice calling system is protected by pending patent applications. The patent covers the system and method for interactive voice calls with custom call titles, real-time floating emoji reactions, and contextual call experiences within a community-driven sports application.

    Partners are granted a license to use Squad Line as part of their SDK integration agreement. Unauthorized reproduction of Squad Line's interactive calling features outside the SDK is prohibited.
